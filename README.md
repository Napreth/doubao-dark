# doubao-dark

豆包网页版深色模式增强 Userscript。

提供 **浅色 / 跟随系统 / 深色** 三种主题模式，并补充豆包部分区域的深色适配，包括 Markdown、代码块、表格、图表和功能浮层等。

## 安装

需要先安装 Userscript 管理器，例如 [Tampermonkey](https://www.tampermonkey.net/) 或 [Violentmonkey](https://violentmonkey.github.io/)。

然后安装 `doubao-dark.user.js` 即可。

## 使用

安装后打开 [豆包网页版](https://www.doubao.com/)。

可通过页面右上角的主题切换按钮选择：

* 浅色
* 跟随系统
* 深色

也可以通过 Userscript 管理器菜单切换主题或隐藏页面切换按钮。
